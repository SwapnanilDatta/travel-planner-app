# ROADMAP.md

# Smart Travel Media Intelligence System

## Goal

Extend the existing group travel planner by transforming uploaded media into structured travel preferences.

Instead of only supporting semantic image search:

```text
Search: "beach"
→ Return beach photos
```

the system should automatically:

* Organize trip photos
* Generate albums
* Infer group interests
* Feed preferences into itinerary generation

---

# Current Architecture

```text
User Uploads Images
        ↓
Local Storage
        ↓
CLIP Embedding Generation
        ↓
Vector Store
        ↓
Semantic Search
```

Current functionality:

```text
Search:
"beach"

Output:
Top matching beach images
```

---

# Phase 1 — Media Categorization Engine

## Objective

Convert raw CLIP embeddings into meaningful travel categories.

### Categories

```python
CATEGORIES = {
    "Beach",
    "Food",
    "Museum",
    "Hotel",
    "Nature",
    "Shopping",
    "Nightlife",
    "Temple",
    "Adventure",
    "Transportation"
}
```

---

## Category Description Generation

For every category create descriptive text.

Example:

```text
Beach:
sandy beaches, ocean, sea, shoreline, sunset, water sports

Museum:
historical artifacts, galleries, exhibitions, architecture

Food:
restaurants, dishes, street food, local cuisine
```

---

## Category Embedding Creation

Generate CLIP text embeddings:

```text
encode_text(category_description)
```

Store once during initialization.

```text
Beach Embedding
Food Embedding
Museum Embedding
...
```

---

## Image Classification

For every uploaded image:

```text
Image
 ↓
CLIP Image Encoder
 ↓
Image Embedding
 ↓
Cosine Similarity
 ↓
Nearest Category
```

Example:

```text
Image

Beach Similarity = 0.91
Food Similarity = 0.23
Museum Similarity = 0.11

Result:
Beach
```

Store:

```json
{
  "image_id": 12,
  "category": "Beach",
  "confidence": 0.91
}
```

# Phase 3 — Preference Mining

## Objective

Infer travel interests from uploaded media.

---

## Individual Preference Profile

For each user:

```text
Beach Photos = 20

Food Photos = 10

Museum Photos = 5
```

Normalize:

```json
{
  "Beach": 57,
  "Food": 29,
  "Museum": 14
}
```

---

## Group Preference Profile

Aggregate all members.

Example:

```json
{
  "Beach": 42,
  "Food": 31,
  "Nightlife": 18,
  "Museum": 9
}
```

Store:

```json
group_preferences
```


Future:

```text

Planning Agent

Personalized Itinerary
```

---

## Example

Detected:

```json
{
  "Beach": 50,
  "Food": 30,
  "Museum": 10,
  "Nightlife": 10
```

Planner should prioritize:

* Beach activities
* Water sports
* Local restaurants
* Sunset viewpoints

Planner should reduce:

* Museum visits
* Historical tours

````
# Phase 5 — Duplicate Detection

## Objective

Remove redundant photos.

---

## Similarity Detection

For every new image:

```text
New Image Embedding
 ↓
Nearest Neighbor Search
 ↓
Similarity Score
````

If:

```text
similarity > 0.95
```

mark as duplicate.

# Final Deliverable

The system should not simply search photos.

The system should:

1. Understand uploaded travel media.
2. Organize media automatically.
3. Learn group interests.
4. Influence itinerary recommendations.
5. Reduce manual trip planning effort.

This turns the media module into a recommendation signal for the travel planning agent rather than a standalone image search feature.
